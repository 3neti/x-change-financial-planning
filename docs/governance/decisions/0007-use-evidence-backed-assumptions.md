# 0007 — Use Evidence-Backed Assumptions

## Status

Accepted

## Context

Financial models are only as reliable as the assumptions that drive them.

Assumptions should eventually be traceable to evidence.

## Decision

Every material planning assumption should ultimately reference one or more of:

- observed deployment experience
- pilot results
- stakeholder interviews
- published research
- documented expert judgment
- reproducible calculations

## Consequences

- assumptions become reviewable
- sensitivity analysis becomes meaningful
- investor discussions become more transparent
- evidence can evolve without changing repository architecture
