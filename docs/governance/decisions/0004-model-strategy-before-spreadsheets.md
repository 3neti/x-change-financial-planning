# 0004 — Model Strategy Before Spreadsheets

## Status

Accepted

## Context

The initial financial planning question was how to prepare a 12–36 month financial projection.

The discussion revealed that this is not primarily an Excel problem. A spreadsheet only expresses a chosen strategy numerically.

Without a strategic model, financial projections risk becoming arbitrary.

## Decision

The repository will first preserve the business strategy narrative, adoption model, scenario framework, operating assumptions, and capital logic before creating detailed financial spreadsheets.

## Consequences

- Financial projections must be derived from an explicit operating plan.
- Capital requirements should emerge from strategy.
- The model should not be built backward from an assumed investment amount.
- Investors should be shown the logic of sustainability, not merely numerical optimism.
