# 0010 - Editorial Manuscripts Precede Repository Persistence

## Status

Accepted

## Context

Long-form strategic writing evolves through iterative editorial composition.

Updating repository working documents during every editorial revision creates noise and weakens the repository as a durable knowledge system.

## Decision

Editorial manuscripts shall be composed and approved before repository persistence.

Repository documents are published artifacts of the editorial process.

Codex performs publication rather than editorial authorship.

## Consequences

- Editorial quality improves.
- Repository history becomes cleaner.
- Discovery remains separate from publication.
- The same workflow used by x-change Monographs now applies to execution memoranda and future long-form strategic documents.
