# Future Knowledge Commands

This document describes the long-term command surface for the x-change Financial Planning knowledge framework.

The repository is evolving toward a queryable knowledge system, but the commands themselves are intentionally not implemented yet.

## Intended Commands

- `knowledge:status`
- `knowledge:graph`
- `knowledge:impact`
- `knowledge:assumptions`
- `knowledge:missing-evidence`
- `knowledge:orphans`
- `knowledge:investor-pack`

## Purpose

These commands would eventually inspect repository relationships, surface missing links, summarize assumptions, and compile downstream outputs from the knowledge graph.

## Current Constraint

Do not implement command logic yet.

The repository architecture should stabilize first so later commands operate on a consistent knowledge model.
