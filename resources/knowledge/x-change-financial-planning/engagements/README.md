# Engagements

This directory contains stakeholder-specific workspaces.

An engagement is not the canonical strategy itself.

An engagement assembles canonical concepts, working strategy, evidence, and open questions for a specific audience or transaction.

Examples may include:

- founding execution partner proposal
- DBP proof of concept
- IFX pilot
- university incubation
- bank partnership
- investor roadshow
- strategic funding round

Engagements may contain source notes, working documents, and assets.

Generated outputs belong under `build/`.
