# x-change Financial Planning Overview

## Background

This repository preserves the financial planning knowledge system for the x-change ecosystem.

The work began with the need to prepare investor-facing 12–36 month financial projections.

The discussion revealed that the correct first step is not to build a spreadsheet, but to define the economic strategy that the spreadsheet should express.

## Core Thesis

Strategy precedes spreadsheets.

x-change should be modeled as institutional financial infrastructure, not as a consumer internet startup.

The primary planning axis is institutional adoption.

The primary economic unit is the institutional program.

## Current Strategic Direction

The financial model should support a staged path:

1. Proof of Execution / Pre-Incubation
2. Incubation
3. Conservative Operations
4. Expected Growth
5. Acceleration

The immediate objective is to raise execution capital for a successful proof-of-concept path, including DBP and Paynamics-related validation.

The model must also account for bridge revenue while waiting for larger funding or institutional adoption.
